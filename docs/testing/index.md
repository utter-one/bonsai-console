# Testing Overview

The **Testing** section lets you automate conversation testing against your project configuration. Define AI-powered **testers** (personas), create **scenarios** that specify conversation flows and expected outcomes, then execute **test runs** to validate behaviour across multiple conversations simultaneously.

This is different from the [Playground](../guide/playground) — while the Playground is for manual, one-at-a-time interaction, Testing lets you run batches of conversations automatically with AI personas that simulate real users.

## What You'll Find

| View | Purpose |
|---|---|
| [Playground](../guide/playground) | Manual conversation testing with text or voice |
| [Testers](./testers) | Define AI personas that act as test users |
| [Scenarios](./scenarios) | Create test scenarios with expected outcomes |
| [Test Runs](./test-runs) | Execute and review scenario test results |

## Project Scope

All Testing resources are scoped to the currently selected project. Select a project from the dropdown in the top navigation bar before creating testers or scenarios.
